# Aholo 提交清单

## 必交

- [ ] 完整可运行 Demo，或评委可访问的视频链接
- [ ] 项目报告 PDF/PPT 或报告链接
- [ ] GitHub 项目链接或源码压缩包
- [ ] 报告和 README 中明确 Aholo Lux3D 的使用位置
- [ ] 报告中有过程截图
- [ ] 报告中有至少一组资产迭代前后对比
- [ ] 所有链接使用无登录或评委可访问权限

## 报告最少内容

1. 项目简介和体验目标
2. 为什么选择 3D 规则怪谈
3. 核心交互流程图
4. 三条规则和三种结局
5. Aholo Lux3D 资产生成记录
6. 一组失败到可用的迭代对比
7. 最终效果截图
8. 当前限制和下一步
9. Demo / 视频 / GitHub 链接
